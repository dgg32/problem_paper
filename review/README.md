# Review frontend (Phase 5)

Human triage queue for the fraud-paper scanner. Generated by
[`graph_processing/build_review_page.py`](../graph_processing/build_review_page.py):

```bash
python graph_processing/build_review_page.py --top 50
```

This writes `review/index.html` — a single self-contained page (inline CSS/JS,
no external resources) ranking the top-N not-yet-retracted candidates with
expandable, named, sourced evidence per signal.

## ⚠ This page is private — do not commit or share it

`index.html` shows retraction- and misconduct-adjacent flags tied to **real,
named researchers**. Per `plan.md` §7 (keep the review queue private during the
POC) and §0 (every output is a hypothesis for human review, never an
accusation), the generated HTML is **git-ignored on purpose** (`review/*.html`
in `.gitignore`) and must not be published as a web artifact, shared onward, or
committed. Regenerate it locally from the graph instead of passing the file
around.

## Opening it

Open `review/index.html` directly in a browser, or serve it locally:

```bash
python -m http.server 8899 --bind 127.0.0.1 --directory review
# then visit http://127.0.0.1:8899/index.html
```
